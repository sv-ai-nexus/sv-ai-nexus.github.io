# 3. 비고 / 다음 단계

1. **큐레이션 원칙:** 현 단계는 *브랜드 대표성* 우선. 접촉·파트너십 실제 추진은 단계적으로 확장.
2. **수출통제 카테고리(국방·우주·양자):** 본격 추진 전 별도 법률/규제(ITAR·EAR·CFIUS) 검토 선행 필요.
3. **Erudio Bio:** 본 JV 범위에서 분리 유지. 바이오는 시장으로만 다룸.
4. **다음 단계 제안:** Tier 1(AI·반도체)에서 **우선 접촉 대상 5~10곳**을 선정하여 정부 제안서에 "1차 협력 풀"로 구체화.
